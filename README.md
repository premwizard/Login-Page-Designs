## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/premwizard/Login-Page-Designs.git
```

2. Open any project folder

```bash
cd MY-LOGIN-PAGE-1
```

3. Launch the `index.html` file in your browser.
